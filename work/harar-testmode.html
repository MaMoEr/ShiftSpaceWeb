Så öppnar du testläget

Testläget är till för dig som testar eller granskar appen. Du behöver ett lösenord, som du får av ShiftSpace.

  1. Tryck på ?-ikonen.
  2. Tryck på i-ikonen.
  3. Tryck på ShiftSpace-logotypen fem gånger.
  4. Skriv in lösenordet.

Inget lösenord?

Lösenordet står inte här. Kontakta oss via kontaktformuläret så skickar vi det.
